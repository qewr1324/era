Build a complete VSCode extension called "ERA - Elastic Runtime Automation".

## CORE CONCEPT
ERA is an n8n-like visual workflow builder inside VSCode that:
1. Allows users to build automation workflows visually (drag & drop nodes, connect them)
2. Compiles the visual workflow into executable JavaScript code
3. Bundles all dependencies into a single minified file
4. Exports a standalone .js file that runs anywhere with Node.js

Unlike n8n which requires its own server to run workflows, ERA generates independent, portable code.

NODE TYPES - Complete Specification
1. TRIGGERS

Webhook Trigger

    Creates HTTP server to listen for incoming requests

    Config: method, path, port, secret, responseTemplate

    Output: { body, headers, query, params }

Cron Trigger

    Schedules workflow execution

    Config: cronExpression, timezone

    Standard cron syntax: "*/5 * * * *"

File Watcher Trigger

    Watches filesystem for changes

    Config: path, events (create/modify/delete), pattern

    Uses chokidar

Manual Trigger

    User-triggered execution

    Config: inputSchema (JSON Schema for input validation)

2. ACTIONS

HTTP Request

    Makes HTTP/HTTPS requests

    Config: method, url, headers, body, auth (basic/bearer/oauth), timeout

    Supports: axios with full config

Run Command

    Executes shell commands

    Config: command, cwd, env, timeout, shell

    Captures: stdout, stderr, exitCode

Read File

    Reads file content

    Config: path, encoding

    Output: { content, path, size }

Write File

    Writes content to file

    Config: path, content, encoding, mode

Git Clone

    Clones git repository

    Config: url, branch, depth, auth

Docker Run

    Runs Docker container

    Config: image, command, ports, volumes, env

Kubectl

    Executes kubectl commands

    Config: command, namespace, kubeconfig

SSH Command

    Executes command on remote server

    Config: host, port, username, privateKey/password, command

SQL Query

    Executes SQL queries

    Config: connection (host, port, database, user, password), query

3. TRANSFORMATIONS

JSON Transform

    Transforms data using JSONPath or template

    Config: inputPath, template, outputPath

Filter

    Filters array based on condition

    Config: arrayPath, condition

Encrypt/Decrypt

    Encrypts/decrypts data

    Config: algorithm, key, data

4. NOTIFICATIONS

Slack Message

    Sends message to Slack

    Config: webhookUrl, channel, message, attachments

Send Email

    Sends email

    Config: smtp, from, to, subject, body (HTML supported)

5. FLOW CONTROL

If Condition

    Branch based on condition

    Config: left operand, operator, right operand

    Operators: ==, !=, >, <, >=, <=, contains, matches, empty, exists

Loop

    Iterates over array

    Config: arrayPath, mode (sequential/parallel), maxConcurrency

Parallel

    Executes branches simultaneously

    Config: waitForAll (true/false)

Delay

    Pauses execution

    Config: duration, unit (ms/s/m/h)

Try/Catch

    Error handling wrapper

    Config: maxRetries, retryDelay, fallbackNode

COMPILER - Graph to Code Generation

The compiler must:

    Parse the .era.json workflow file

    Validate (no cycles, all edges reference existing nodes, type compatibility)

    Topological Sort nodes by edges to determine execution order

    Generate Code using template system:

javascript

// Generated output structure:
// 1. Import all required packages
// 2. Define runtime context manager
// 3. Define each node as a function
// 4. Define main execution flow
// 5. Export for module usage & CLI execution

import axios from 'axios';
import { exec } from 'child_process';
import { promisify } from 'util';

const execAsync = promisify(exec);

class WorkflowRuntime {
  constructor() {
    this.context = {};
    this.nodes = {};
    this.logs = [];
  }
  
  log(level, message, data) {
    const entry = { timestamp: new Date(), level, message, data };
    this.logs.push(entry);
    console[level](message, data);
  }
  
  resolveTemplate(template, context) {
    return template.replace(/\{\{(.+?)\}\}/g, (match, path) => {
      return this.resolvePath(path.trim(), context);
    });
  }
  
  resolvePath(path, context) {
    const parts = path.split('.');
    let value = context;
    for (const part of parts) {
      if (value === undefined || value === null) return '';
      value = value[part];
    }
    return value ?? '';
  }
  
  registerNode(id, fn) {
    this.nodes[id] = fn;
  }
  
  async execute(input) {
    // Main execution logic
  }
}
